# Slingshot Siege (impact-damage-system)

Slingshot Siege is the playable Angry-Birds-style game grown from the most complete of four course-era physics sketches. Built on typed Matter.js, you drag a bird on the slingshot, aim with a dotted ballistic trajectory guide, and release to demolish box-and-log structures sheltering pigs. Every collision converts an impulse estimate — relative speed weighted by the lighter body's mass — into damage past a threshold, so gentle contacts are harmless while hard hits chip health until blocks and pigs shatter, tinted red as they weaken. Three levels ship as JSON generated by a Python level builder that turns ASCII grid layouts into structures, with a HUD tracking birds, score, and a star rating by birds spared. Win/lose rules, the damage model, level validation, and launch math are pure TypeScript modules under a 30-test Vitest suite; GitHub Actions runs lint, tests, and build, and Vercel deploy config ships in-repo.

## How to play

Drag the bird back (mouse or touch), watch the dotted arc, release to fire.
Destroy every pig to clear the level; you lose when the quiver is empty and pigs
remain — but the last bird's flight always gets to resolve first.
Stars: 1★ for the win, 2★ with one bird spared, 3★ with two or more.

## The damage model (src/systems/damage.ts)

- **Impulse proxy** — for each `collisionStart` pair:
  `impulse = relativeSpeed × min(massA, massB)` (a static partner defers entirely to
  the dynamic body; static–static transfers nothing).
- **Damage** — `max(0, impulse − threshold) × scale`, so resting stacks and grazes do
  nothing while direct hits scale linearly.
- **Health** — boxes 60, logs 80, pigs 40; health floors at zero and destruction pays
  out score (100 / 150 / 500). Damage tint shows remaining health at a glance.

## Levels as data

`public/levels/level{1..3}.json` follow the schema validated by
`src/systems/levels.ts`. They're emitted by the Python level builder from plain
ASCII layouts (`B` box, `L` log — runs merge into one beam, `P` pig):

```bash
python scripts/level_builder.py scripts/layouts/level2.txt public/levels/level2.json
```

Add a layout file, run the script, and the level-select picks it up with one constant.

## Architecture

- `src/systems/` — pure, tested: `damage.ts`, `rules.ts` (win/lose/stars),
  `levels.ts` (parse + validate), `launch.ts` (drag clamp, launch velocity, ballistic arc).
- `src/game/world.ts` — the only Matter-aware module: bodies, slingshot state machine
  (aiming → dragging → flying), collision-damage queue, settle detection.
- `src/game/render.ts` — Canvas2D drawing with the original sprite art.
- `src/main.ts` — level loading, pointer input, HUD, verdict overlay.

## Tech stack

## Local development

```bash
npm install
npm run dev
npm test
npm run lint
npm run build
```

## Testing

`tests/damage.test.ts` (threshold/linearity, mass rules, destruction chain),
`tests/rules.test.ts` (win/lose incl. last-bird-in-flight edge, star mapping),
`tests/levels.test.ts` (shipped-fixture pins, log merging, validation errors),
`tests/launch.test.ts` (stretch clamping, velocity math, parabola points).

## Deploy

```bash
npm i -g vercel   # once
vercel deploy
```

`vercel.json` is preconfigured for the Vite static build.

## Project history

The 2021 original was the final stage of a p5+Matter course series: hardcoded boxes,
logs and pigs with a drag-and-fly bird. Rebuilt in 2026: data-driven levels, a real
damage model, win/lose/stars, a trajectory guide, tests, CI, and deploy config —
original sprite art retained.
